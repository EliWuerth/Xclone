# XClone
(In-progress / not finished)

## Project Overview

**XClone** is a mobile application developed using Swift for iOS, designed to provide users with a seamless experience in managing their tasks and activities. The application features a user-friendly interface, allowing users to create, edit, and delete tasks, set reminders, and categorize their activities for better organization.

### Key Features

- **Task Management**: Users can create, edit, and delete tasks easily.
- **Reminders**: Set reminders for tasks to ensure timely completion.
- **Categorization**: Organize tasks into different categories for better management.
- **User -Friendly Interface**: Intuitive design for easy navigation and usage.

## Installation

To run the project locally, follow these steps:

### Prerequisites

- **Xcode**: Ensure you have Xcode installed on your macOS system. You can download it from the [Mac App Store](https://apps.apple.com/us/app/xcode/id497799835?mt=12).
- **Swift**: The project is built using Swift, so ensure you have the latest version compatible with your Xcode.

### Steps to Install

1. **Clone the Repository**:
   bash
   git clone https://github.com/EliWuerth/Xclone.git
   cd Xclone
   
2. Open the XClone.xcodeproj file in Xcode.
   Build and Run:

3. Select a simulator or a connected device.
   Click on the "Run" button in Xcode to build and run the application.

### Usage
- Launch the application on your iOS device or simulator.
- Create a new task by tapping the "+" button.
- Fill in the task details, set a reminder if needed, and categorize the task.
- View your tasks in the main interface, where you can edit or delete them as necessary.
